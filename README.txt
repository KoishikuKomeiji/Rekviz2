REKVIZITOR 2.0 — Android PWA

1. Разместите содержимое папки на HTTPS-хостинге (например GitHub Pages) или запустите на localhost.
2. Откройте в Chrome Android, затем меню → Добавить на главный экран / Установить приложение.
3. В настройках импортируйте JSON-резервную копию Rekvizitor 1.0. База 1.0 не затрагивается.
4. Создайте ракурсы комнаты, полки и точки на фотографиях. Для точек используйте складской код или ID полки.
5. Экспортируйте резервную копию регулярно, особенно перед обновлением.

ПРИМЕЧАНИЯ
- APK в архиве нет. Это локальная PWA, первый запуск требует размещения на HTTPS и загрузки в браузере.
- Фото комнат и предметов сохраняются в IndexedDB. Никаких запросов к серверу для сохранения данных нет.
- Горизонтальный режим основной; вертикальный не оптимизирован.
- Перетаскивание: долгое нажатие на карточку и перенос на папку или другую карточку; доступно и меню «Переместить».
- Удаление комнаты и полки пока не предусмотрено во избежание потери связанных данных.
- Для редактирования папки в текущем интерфейсе используйте её карточку через открытие и отдельное действие; расширенный редактор будет доработан.
